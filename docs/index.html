About This Portfolio

This portfolio represents both where I started in software development and how my approach to building and testing software has developed throughout my Computer Science program.

My professional background has given me extensive experience working with complex systems, testing, integration, and real-world operations. I am now applying that experience as I transition further into software test automation and software engineering.

My goal is to combine the perspective I have gained from testing and operating real systems with stronger software development skills. Rather than treating testing and development as completely separate areas, I am especially interested in building software that is testable, maintainable, and reliable from the beginning.

Project Evolution

The capstone is designed around improving an existing artifact rather than presenting only the finished result.

Original CS-320 Application

Developed Contact, Task, and Appointment services in Java with validation and automated tests based on defined software requirements.

Architecture & Engineering

Reworked the project into a cohesive architecture with reusable repositories, shared validation, clearer responsibilities, and improved data safety.

Algorithms & Data Structures

Added practical collection processing through searching, filtering, Comparators, and sorting while retaining efficient HashMap lookup when an exact record ID is known.

Database Integration

The next stage will move the project beyond in-memory storage by implementing persistent data management through the existing repository abstraction.

Testing the Enhancement

Automated testing was expanded alongside the algorithms and data structures enhancement. The current test suite validates searching, case-insensitive matching, sorting, filtering, empty collections, invalid search input, and chronological appointment behavior.
